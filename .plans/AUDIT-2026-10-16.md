# BidBrain: spec vs reality audit (16 Oct 2026, 06:15 IST)

Three read-only auditors went through every item in `.plans/bidbrain-spec.md`. Each checked the code and ran it
against the live graph: tool calls, the oracle, pytest, the orchestrator on graph copies, and the read-only API
and MCP endpoints. No LLM calls were made.

Statuses:

- **BUILT**: works as promised.
- **PARTIAL**: some of it is missing.
- **CHANGED**: built differently, on purpose.
- **MISSING**: not there.

✅ marks items fixed after the audit. Those fixes are in commits `44334eb` and `6bf659d`.

## Headline

The core works and is well tested:

- **Graph:** 7,544 nodes, 12,839 edges, 1,648 claims, 114 decisions.
- **Tools:** 25, with 24 on MCP.
- **Tool oracle:** 354/354, and 21/21 on true gold.
- **Conflict engine:** precision/recall 1.00 on JSON and on PDF.
- **Sessions:** per-session `GRAPH.COPY`.
- **UI:** every page works.

The benchmark now has real numbers.

**What is still missing for submission:**

- A live deployment.
- A demo video.
- Pushing 15+ commits.
- Committing the results files.
- Filling in the README and blog tables.

**What is weaker than the spec says:**

- The "six agents": four are deterministic code steps.
- The Verifier flags errors but does not act on them.
- The bid pack carries no page citations.
- Two clause types are missing: JV share credit and bank guarantee.
- The benchmark does not include the multi-agent system.

**Honesty notes. These must go in the README and blog.**

- **BidBrain run 1 vs run 2.** Run 1 scored TND .313. In that run the agent's short tool description hid
  `qualify_clause`'s parameter names, and keys it invented were silently ignored. Commit `04e9060` documented and
  validated the parameters. BidBrain was then re-run on all sets: TND .896, Q333 .646 → .640.
  - Run 1 is kept in `data/eval/results/run1/`.
  - The baselines do not use tools and were not re-run.
- **Noise.** Q333 changed by about ±5% between runs (19 right→wrong, 17 wrong→right). These are single runs with no
  confidence intervals.
- **Constant baselines.** On ABS, always answering 0 (.427) beats vector RAG. On TND, the majority answer (.472)
  beats both baselines.

## 7. Doc claims to correct

1. **EXPLAINER says the agent has "16 named tools".** It has 17.
2. **EXPLAINER says the loop is "about 100 lines".** It is 182.
3. **BLOG says "we gave the agent 25 tools".** The Q&A agent gets 17; the registry has 25.
4. **README says the Assembler writes a memo "with document and page citations".** Not true today.
5. **README says the Verifier "fails loudly".** It flags the error, but the recommendation is not changed.
6. **"A handoff is a graph write the next agent reads."** True except for EvidenceHunter → AbsenceAuditor.
7. **PDF path "first run F1 0.976 / extraction 86.7%".** Not saved as an artifact. Keep it only if stated as an
   unsaved first run.
8. **"Persistent" procedural memory.** Rules live in the visitor's session graph, for up to 24 h. They are never
   promoted to the base graph.
